# DAG STUDIO CMS

Универсальная модульная CMS для сайтов администраций, компаний, организаций и магазинов.

Рабочая ветка: `main`. Деплой: GitHub → FTPS → `cms.dagstudio.ru`.

> Проект находится на стадии разработки. Не используйте для реальных персональных данных, заказов или платежей до проверки безопасности и релиза.
